# Bio Rig v1 — 角色建模／綁骨技術規格

狀態：**建模規格與可互動的骨架測試場已建立**。此文件不是宣稱已完成高擬真原畫的正式 GLB；先建立可驗收的製作基準，再逐步將手工拓樸（retopology）與 UV 紋理替換進來。

## 1. 目標與驗收

**目標**：保持「沼氣領航員拜爾」原始設定圖正面、3/4、側面及背面的辨識度，同時具備真正可動的肢體及可在 GitHub Pages 截取透明 PNG 的介面。

**必須符合**
1. 模型採公分或公尺皆可，但 GLB 標準是 **公尺**，`+Y` 向上、`+Z` 為正面，雙腳落在地面（Y=0），模型中心位於兩腳之間。
2. 頭殼近似**橫向圓角矩形**，不是橢球；深灰綠螢幕面積大、嵌入綠色頭框，側面有圓形耳罩。
3. 安全帽是**圓拱帽殼＋寬外翻前帽簷＋側邊稜線＋正面白邊葉片 logo**；不可用單顆椭球取代。
4. 身體短而寬、肢體偏短；手套／靴子有誇張卡通體積但輪廓清楚，機械連接環可見。
5. 胸前有彩色區段的沼氣儀表以及葉片圖案，眼睛的螢光綠形狀與表情保持一致。
6. 預覽頁在旋轉、換姿勢後仍可輸出含 Alpha 通道的 PNG，且不能把棋盤格烘焙進 PNG。
7. 原始 v0.4 頁不刪除：在完成母版比對前，新的骨架測試場與舊版本並存。

## 2. 尺寸比例（**初步建模估值**，非圖面測量）

以整體身高 (H=1)：
- 安全帽＋頭部約 0.43H；頭部寬度約 0.49H（以正視圖、含耳罩）。
- 軀幹約 0.27H；腿部含靴子約 0.26H；連接處約 0.04H。
- 帽簷寬度約為頭殼寬度的 1.10–1.20 倍。
- 眼睛置於螢幕內左右對稱，神情偏溫暖而非人類寫實。
- 具體數值將以**原始角色圖的正面、側面描線重合比較**修訂，不應視為已定版尺寸。

## 3. Mesh 分件（物件名稱固定）

`BodyShell`（可蒙皮）、`HeadShell`（頭骨關聯的硬表面）、`FacePanel`（獨立圓角矩形）、`HelmetShell`、`HelmetBrim`、`HelmetLeaf`、`EarL/R`、`ArmSkinL/R`（蒙皮）、`GloveL/R`、`LegSkinL/R`（蒙皮）、`BootL/R`、`ChestGauge`、`FaceEyes`、`FaceMouth`。
頭盔和面板不需要蒙皮扭曲，只需隨 `head` 骨骼移動。臂部／腿部要有**連續頂點＋漸進權重**，不能將每節做成無縫隙的硬球後聲稱是蒙皮。

## 4. Armature 骨架樹

```text
root
└── hips
    ├── spine
    │   ├── chest
    │   │   ├── neck
    │   │   │   └── head
    │   │   ├── upperArm.L
    │   │   │   └── forearm.L
    │   │   │       └── hand.L
    │   │   └── upperArm.R
    │   │       └── forearm.R
    │   │           └── hand.R
    ├── thigh.L
    │   └── shin.L
    │       └── foot.L
    └── thigh.R
        └── shin.R
            └── foot.R
```

手指第一階段可用獨立造型／靜態手勢；進入精細比讚及 STOP 姿勢時才加 finger bones。

## 5. Skin weights

- 頭盔、螢幕、眼睛、logo：100% `head`；眼睛、嘴巴優先用紋理／shape keys，禁止隨手臂蒙皮變形。
- 上臂到前臂、手腕以 elbow/wrist 周圍約 15–25% 肢段長的平滑過渡帶配置頂點權重；每頂點最多 4 個 joint influences。
- 手套可 100% `hand.L/R`；肩關節附近軀幹表皮最多混合 `chest` 和上臂權重。
- 腿部跨膝／踝同理。檢查抬手 60°、90°、伸直、握手等時是否破面、穿模或塌陷。
- 以 GLB 驗證實際 `skins`／`JOINTS_0`／`WEIGHTS_0`，不是只存在骨架名稱。

## 6. 材質與視覺

| 部位 | HEX | 說明 |
|---|---|---|
| 主體綠 | `#7BC043` | 漸層高光由燈光／手繪陰影輔助 |
| 深綠 | `#2E6B3F` | 外框、關節、手套 |
| 面板 | `#394A41` | 低反光深灰綠螢幕 |
| 安全帽 | `#FFD42A` | 卡通黃，保留白色高光 |
| 發光綠 | `#B8FF66` | 眼睛／表情 |
| 儀表橘 | `#FF9A3C` | 指示區段 |
| 警示紅 | `#E53935` | 高風險、STOP |

建議 Blender 使用 **Principled BSDF**，眼睛用少量 emission；網頁使用 color-managed sRGB，避免過度曝光使顏色偏白。可加 Ink/Outline 輪廓（選用），但不應依賴 2D 描邊掩飾錯誤比例。

## 7. 表情與姿勢規範

表情：`smile`, `happy`, `focus`, `think`, `alert`, `stop`。建議以 shape keys 或局部獨立的 LED 面片實作，表情切換不可改變臉框拓樸。

首批姿勢：`formal`（正面站立、手垂放）、`welcome`（右手抬起招呼）。後續：`map`, `inspect`, `checklist`, `think`, `caution`, `stop`。

動作匯出 glTF animations，例如 `Bio_Formal`, `Bio_Welcome`；若動畫 clip 尚未完成，Pages 需以骨骼四元數作預設姿勢控制。要避免直接旋轉最外層 mesh 來假裝在控制骨骼。

## 8. 交付結構與版本

- `assets/bio-rig-v1.json`：命名、層級、材料、規格的機器可讀資料。
- `rig-preview.html`、`rig-preview.js`：v1 **骨架／蒙皮技術驗證頁**（與正式母版分開）。
- `models/Bio_Rig_v1.glb`：在完成正式母版、拓樸、權重後才發布；**尚未完成不得宣稱已存在**。
- `sources/Bio_Rig_v1.blend`：正式 Blender 原始專案；建議保存外部可編輯來源。
- `docs/REFERENCE_CHECKLIST.md`：視角／五官／姿勢對照核對清單。

## 9. 驗收步驟

1. 將正面、3/4、側面、背面渲染與原始角色設定圖並排，對比**輪廓、頭身比、顏色和標誌位置**。
2. 測試正式站姿與歡迎姿勢，檢查上臂彎曲、手腕位置是否自然。
3. 在桌面與手機測試 3D 旋轉、縮放及透明 PNG。
4. Blender 匯出 GLB；以 glTF Validator 驗證，並在 Three.js 使用 GLTFLoader／AnimationMixer 實測。
5. 通過視覺審核後，才將正式主站切換至 GLB；維持舊模型作為回退。

**重要：** 骨架本身不會自動讓角色更像設定圖。外型相似度主要取決於正確描線建模、拓樸、材質／紋理及角度比對；目前的 v1 骨架測試場只驗證後續技術路線。
